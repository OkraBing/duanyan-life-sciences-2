# 60 轮视觉一致性走查（2026-11-29）

跑的是 `review/v60-visual.cjs`。第二个参数是**轮次**，不是文件路径：

```
node review/v60-visual.cjs        全跑 60 轮
node review/v60-visual.cjs 7      只跑第 7 轮
node review/v60-visual.cjs 7-12   跑第 7 到 12 轮
DUMP=/tmp/snap.json node review/v60-visual.cjs 1   顺便把全站快照落盘，方便离线查某个值出现在哪
```

## 和已有几套的分工

- `visual-style.cjs`（8 条）管「有没有违反定稿的禁令」：单侧色条、眉题、渐变字、大块上色。
- `interaction-components.cjs`（11 条）管「同一个控件在**两页**上长不长得一样」。
- **这一套管全站范围内的收敛**：26 个页面摆在一张表上，字号有几档、圆角有几种、墨色有几级、
  投影分几层、同一类容器是不是同一种材质。单页看不出来的毛病——某一页悄悄多出一个 15px、
  某个卡片比别处圆 2px——只有把所有页面的计算值并排才看得见。

做法：先把 26 个页面各走一遍，把每个可见元素的计算值抄下来，之后绝大多数轮次是在这张表上
做断言，不用再开浏览器。需要真交互的轮次（悬停、键盘焦点、弹窗、改视口、深色）自己开页面。

## 修了什么

### 一、定时任务整页是另一套排印（最影响「是不是同一个产品」）

- **字体族不一样**：`.st-layout` 写的是 `"Noto Sans SC"`，其余 25 页是 Geist。
  翻到这一页，字的骨架就换了——这是整轮里最容易被一眼认出来的那处。
- **页面标题 18px**，别处都是 22px；右边那块空态的 h2 反而是 22px，比 h1 还大。
- **正文另有一套 15 / 17 / 14px**，全站是 13 / 12 / 11px。

→ 字体归队；h1 22px，空态标题降到 18px；列表行 13px、行内小字 12px、分组标签 12px。

### 二、同一个控件有九种样子

`.btn` 在九个页面上有九种：字号 11 / 12 / 13 / 14，字重 400 / 500，字色 墨 / 墨二 / 墨三，
圆角 6 / 8。一颗「导出」按钮在两页上一眼能看出不一样大。

→ 收成一种：13px / 500 / 圆角 8 / 墨色。危险操作保留它的红。

顺带：
- **禁用态有五种弱化法**（`--line` / 墨 / 墨二 / 墨蓝 / 墨四），而且禁用的主按钮**还穿着黑实心**——
  黑实心是「这一屏最该点的那个」的标记，禁用了还穿着它会让人一直去点。统一成浅墨 + 浅灰底。
- **返回入口有两种写法**：12px 墨二的描边小按钮，和 13px 墨蓝的文字链。返回是导航不是操作，
  不该长成按钮，统一成安静的文字链（`.pg-back` 的类名也从 `btn btn-gh` 改成了 `lnk`）。
- **工作台页头并排的两颗按钮一颗有描边一颗没有**——并排放着最容易看出来。

### 三、两张表不是同一张表

资料空间和「与你共享」的文件表：表头 11px / 400 / 38 高，单元格 11px；
模型制备那几张表是 12px / 600 / 40 高。翻过去会觉得字忽然变了。按后者归一。

### 四、上一版的收口漏掉了一半页面

上一版把 h1 的字距归零、把页头说明统一成 13px 墨三，但**只写给了六种页头壳子**
（`.rh-header` / `.pg-hd` / `.iteration-head` / `.lv-head` / `.al-page-head` / `.rs-header`）。
用第七种壳子的六个页面（对话、课题详情、资料空间、与你共享、新建工具、新建数据库）漏在外面，
标题还带着 -.01em，说明文字还停在墨二。

→ 改成按 `#view h1` 和 `#view h1+p` 写，不再点名壳子。下次新加一种页头也不会漏。

### 五、台阶上的半档

| 项 | 原来 | 现在 |
|---|---|---|
| 字号 | 11/12/13/14/**15**/16/18/20/22/24/28 | 11/12/13/14/16/18/22/24/28 |
| 区块与卡片标题 | 11/14/**15**/16/**17**/18/**20**/22 七种 | 16（区块与卡片）/ 18（空态与栏目名） |
| 圆角 | 4/5/6/7/8/**8.8**/9/10/12/14/20 十一种 | 6/8/10/12 + 药丸 |
| 图标 | 14/**15**/16/**17**/18/**19**/20/**21**/22 | 14/16/18/20/22 |
| 投影 | 八种（底色分别取 rgb(19,24,38)、rgb(23,26,31)、rgb(14,17,22)） | 贴页面一档 + 浮层一档 + 抽屉一档 |
| 徽标 | 11/12/13/14px 四种 | 11px |

`8.8px` 是 `.55rem` 算出来的，没有人会这样设计。

### 六、颜色用错了地方

- **「已共享」用墨蓝**。墨蓝在这套里表示「可点」或「进行中」，已共享既不可点也不在进行。
  资料空间一屏有三十多个这样的标签，改成中性之后整张表安静很多，名字才是该先看到的东西。
- **设置页的头像是 72px 墨蓝实心圆，还带一圈墨蓝辉光**——全站唯一的大块纯色和唯一的彩色投影。
  跟其他头像一个做法（浅蓝底 + 深蓝字，不投影）。
- **对话页的发送键是墨蓝实心**，全站唯一一个非黑的实心按钮。定稿里实心黑表示「这一屏的主动作」，
  发送就是主动作，用同一个标记。
- **一个结果两种颜色**：「已完成」在实验详情是中性灰、在打分器列表是绿；
  「已接入」在设备管理和数据库用的是深浅不同的两种绿。统一到 `--ok-ink`。

### 七、其它

- **新建打分器一屏有两颗主按钮**：页头那颗「新建批量推理」指向的就是当前页。
  改成「主操作指向别的页时才是主按钮」。
- **返回按钮上出现过「← databasenew」**：路由中文名表漏了后加的几个页面，
  拿不到名字就把路由名原样显示了出来。补齐了 databasenew / toolnew / sharednew / schedulenew 等。
- **窄屏下按钮没跟着放大**：390 宽时输入框是 40px、按钮还是 32px，一排里高低不齐。
- **选中态有五种画法**：页签只加粗 / 页签加 2px 下划线 / 胶囊黑实心（字重还分 400 和 600）/
  分段控件反过来用白块。收到两种：能并排选的用黑实心，分区页签用 2px 下划线。
- **左右留白三种**：多数页 36px，对话页 40px，课题详情 20px。翻页时内容会横向挪一下。
- **课题卡整张可点却没有悬停反馈**，鼠标移上去没有任何动静。
- **等宽排中文**：对话建议、「未接入」「本课题实测」这类词用了等宽，字距会散开。
- **截断的文字看不到全文**：十几处用省略号截断了但没有 `title`。

## 两件 CSS 做不了的，放在 `src/visual-polish.js`

它们取决于**内容**，不取决于选择器：

1. 文字被省略号截掉时补一个 `title`。逐个模板去写要改十几处，下次新加一列又会漏；
   按「量出来真的被截了」补，漏不掉也不会多补。
2. `.num` 的意思是「用等宽排，数字才对得齐」，但有些地方把中文也放了进来。
   按内容判：含中文就退回正文字体。不去各模板里摘 class，是因为同一个类名在别处是对的，
   摘了会把真的数字也弄歪。

## 收口层为什么是一个单独的文件

`src/visual-converge.css`，排在所有样式最后。那些写法分布在 `index.html` 和九个 css 里，
很多是早几代页面留下的；逐条改要动十几处、互相还会打架。这里按「看得见的那一项」收口，
每条写清它在收什么，下次有人想加新值，先会看到这里已经定了几档。

## 25 条红灯是检查写歪了，不是产品的问题

记在这里，免得下次又当成缺陷去「修」：

| 检查 | 它判错了什么 | 改法 |
|---|---|---|
| 字号台阶 / 行高 | 头像首字母、文件类型角标（PDF / FASTA）是**当图形用的字**，不是拿来读的 | 这类字形不参加排印比较 |
| 行高比 | 按钮、页签、表头用行高把文字顶到中间，比值天然偏大 | 单行控件不参加 |
| 控件高度 | `.rs-field` / `.al-field` 是**字段的壳子**，高度随内容走，不是控件 | 只量 input / select / `.ctl-dd` |
| 控件高度 | 搜索框那种 input 自己不画框，框在外层 label 上，量它量到的是文字行高 | 有框或有底色的才算控件 |
| 内边距 / 间隙 | 奇数 padding 本身不是毛病——5px 和 4px 没人看得出来 | 改成「同一个组件在不同页面是不是一样」，差 1–2px 不算 |
| 边框粗细 | `.car` 是用边框画的 **CSS 三角**，它的「边框」是形状本身 | 三角不参加 |
| 边框粗细 | 单边 2px 是页签下划线、日志导轨这类**标记线**，不是描边 | 只有一条边的 2px 放过 |
| 边框色 | 设置页「危险区」那张卡的边是 `--err` 调淡出来的，仍属于这套色 | 色相对得上就算在这套色里 |
| 中性判定 | `--ink-4` 通道差 22，按差值判会被当成「上色」，但它的饱和度只有 10% | 改按饱和度判；近黑近白一律算中性 |
| 大块上色 | 40px 以内的是角标、步骤号、头像、小按钮，本来就该有一块实色 | 门槛提到 40px |
| 底色 | 抽屉的**遮罩**是半透明罩层，不是底色 | 半透明的不参加 |
| 主按钮 | 禁用的主按钮显示的是禁用态，不是「主按钮的样子」 | 禁用的不参加比较 |
| 输入框 | 正处在焦点里的控件显示的是焦点色（新建打分器的第一个输入框会自动聚焦） | 有焦点的不参加 |
| 卡片材质 | `rh-card-section` / `lv-cards` 是卡片里的一段、或排版用的网格容器 | 卡片得有自己的面（有底色） |
| 钉住的头部 | 竖着的二级导航栏也是 sticky，但它自己占一栏，没有内容从它底下滚过去 | 只判横着铺开的 |
| 下拉浮层 | 这套下拉是「看得见的壳 + 藏起来的原生 select」，展开的列表**由系统画，DOM 里没有** | 只在真有自绘浮层时判 |
| 悬停抬起 | `transition-property` 不写时默认就是 `all`——没有时长就根本没有过渡 | 还要看时长 |
| 层级 | 档数多不等于乱，要防的是**交叉**（内容爬到浮层上面） | 改判交叉 |
| 区块小标题 | 窄栏（列表栏、二级导航）里的 h2 是分组标签，不是区块标题 | 只比主内容栏里的 |
| 等宽 | 代码块和文件预览是原样显示文件内容，里面有中文也该等宽 | 排除 pre / code |
| 等宽 | 「凡是 `.num` 都得等宽」这条规则本身不对——有些 `.num` 里装的是中文 | 改判「同一列的数字要么都等宽要么都不等宽」 |
| 按钮文案 | 对话里的建议问句、以对象名命名的入口，本来就是整句或专名 | 只判操作按钮 |
| 全大写 | UNIPROT、AFDB-ALL、FASTA 是大写的**专名**，不是眉题 | 眉题的标志是「全大写 **+ 字距刻意拉开**」 |
| 硬裁 | `.sr` 是读屏专用文本，1×1 像素，不在屏上 | 快照跳过 ≤2px 的元素 |
| 图表配色 | pLDDT 的四档蓝橙是 AlphaFold 的**事实标准**，是读数标尺不是装饰色（源码里就写明了） | 放过这四个颜色，另判它们有没有跑到控件上去 |
| 页面留白 | 两栏页把留白放进了自己的栏里，量 `#view` 的内边距会得出 0 | 改量「标题到它所在那一栏左边」的距离 |
| 页面宽度 | 对话和定时任务是三栏，进去会收起侧栏；对话页里还有一条历史栏 | 改判「左右留白对称」 |

## 两处留着没动，是设计判断不是收口

1. **工作台的「待办 22」和课题卡上的「● 7 项待办」用红。**
   红在这套色里是错误 / 失败 / 危险。待办不是错误，但它确实是工作台上唯一要人立刻处理的东西。
   要不要改成中性或墨蓝，是设计决定，不是一致性问题——检查里把它记成了「已知的刻意用法」。

2. **对话页和定时任务页会把侧栏收起来。**
   这两页是三栏布局，收侧栏是 `navigation.js` 里写好的做法，而且离开时会把侧栏恢复原样
   （第 58 轮在验这一条）。翻页时页框确实会动一下，但这是版式决定。
